# Final Project: Emotion Detection Application

This repository contains the Emotion Detection web application developed as part of the IBM course **Developing AI Applications with Python and Flask**.

## Project Description
The Emotion Detection application uses the Watson NLP library and Embedded AI to analyze user-provided text and determine the emotional tone across five key emotions:
- Anger
- Disgust
- Fear
- Joy
- Sadness

The application identifies the dominant emotion and displays formatted results to the user via a Flask web application interface.
